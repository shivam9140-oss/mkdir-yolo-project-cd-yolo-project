# YOLO Object Detection with Webcam 🎥

This project uses [Ultralytics YOLO](https://github.com/ultralytics/ultralytics) to detect objects in real time using your computer's webcam.

## 🚀 Features
- Real-time object detection using YOLO12s
- Displays bounding boxes, class names, and confidence
- Shows FPS on screen

## 📦 Requirements

Make sure you have Python installed. Then install dependencies:

```bash
pip install ultralytics opencv-python cvzone
